Property Descriptor Lab

Each property on an object carries a descriptor: its value plus three flags that decide what other code may do with it. Every result on this page comes from real Object.defineProperty calls running in your browser, so the errors and outputs are what the JavaScript engine actually produces.

writableCan the value be changed by assignment?
enumerableDoes it show up in Object.keys, for...in, JSON and spread?
configurableCan it be deleted, or its flags redefined?

Getters and setters

§5 · §6

An accessor property has no stored value. Reading it calls get, assigning to it calls set. Leave out the setter and the property becomes read-only.

temperature.fahrenheit

77 °F

circle.area getter only

12.566 area
The area is computed from the radius every time you read it.

acc.balance validated setter

0 balance
The real number lives in a closure variable. Object.keys(acc) is ['balance'] and there is no acc._balance to tamper with.
