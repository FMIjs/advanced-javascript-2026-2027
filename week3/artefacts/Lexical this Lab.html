When to use which

Regular functions for methods

Object methods, prototype methods and class methods need this to be the object they are called on.

Arrows for callbacks inside methods

forEach, map, setTimeout, promises and event handlers. The arrow keeps the method's this.

What arrows can't do

Their this can't be changed with call, apply or bind, and they can't be used with new.
