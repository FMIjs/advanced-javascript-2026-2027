Where each link comes from

new User('Ivan', …)

new creates user and sets its [[Prototype]] to User.prototype.

Employee.prototype = Object.create(User.prototype)

Makes a fresh object whose [[Prototype]] is User.prototype. This is the "extends" link.

Object.defineProperty(Employee.prototype, 'constructor', …)

The fresh object had no own constructor, so it would have inherited User. This puts Employee back, non-enumerable like the default.

Employee.prototype = User.prototype ✗

Would make both names point at one object. Adding raise would give every user a raise too.
